# 시장 이벤트 영향 분석

`market-event-impact`는 **“무슨 일이 있었나?”와 “시장은 왜 그렇게 움직였나?”**를 함께 답하는 한국어 대화형 시장 리서치 스킬이다. FOMC·CPI처럼 예정된 발표부터 은행 파산, 신용등급 강등, 관세, 지정학적 충격까지 사건의 형태에 맞춰 공식 발표와 당시 보도, 검증된 가격을 연결한다. 금리 → 외환 → 주식 등 전달경로를 실제 관측값과 대조하고, 일치·혼재·반대·미확인을 구분한다. D-1/D0/D+1/D+5 표는 결론을 뒷받침하는 증거로 사용하며, 검증 가능한 유사사례와 다음 확인 일정까지 짚는다. GS Quant의 `event_study`·`event_impact_analysis`·`CalendarAlignment` 구조를 방법론적 참고점으로 삼았다.

## 지원 범위

- 통화·재정·무역정책, 경제지표
- 기업실적·규제
- 은행·신용·국가신용 사건
- 지정학·원자재 공급충격
- 급락·쇼트스퀴즈 등 시장기능 사건

사건별 whitelist를 요구하지 않는다. 확인된 사건명·기준일·직접 출처가 있으면 Generic Engine으로 처리하며, FOMC·금통위·ECB·물가·고용·실적은 추가 세부항목을 읽는 선택적 adapter다.

## 핵심 동작

1. 자유 문장에서 사건 후보를 찾되 날짜와 출처는 추측하지 않는다.
2. 사건유형과 전달경로로 금리·신용·주식·FX·원자재·변동성 중 관련 자산을 선택한다.
3. 각 시장의 마감시각과 관측 캘린더에 맞춰 이벤트 윈도를 계산한다.
4. 공식자료·시장기사·가격을 분리해 인과의 근거 강도를 표시한다.
5. 이름이 아니라 사건유형·충격 메커니즘·가격반응으로 과거 사례를 비교한다.

실시간 호가, 사전 예측, 매매 신호와 투자 추천은 범위 밖이다. 필요한 확정 종가가 공식 원천에 없을 때 Investing.com 역사적 데이터는 시장가격 보강에만 사용할 수 있다.
